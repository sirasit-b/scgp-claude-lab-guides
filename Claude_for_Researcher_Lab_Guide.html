Claude in Chrome · ให้ Claude ช่วยทำงานบนเว็บ

Claude in Chrome คือ Extension (ส่วนเสริมของเบราว์เซอร์) ที่ให้ Claude อ่านหน้าเว็บ คลิก พิมพ์ เปลี่ยนหน้า และกรอกฟอร์มใน Google Chrome ให้ได้ ใช้ได้ทั้งจากแถบด้านข้างของ Chrome และสั่งจาก Claude Cowork ให้ไปทำงานบนเว็บแล้วนำผลกลับมาเป็นไฟล์ในเครื่อง

ติดตั้งและเปิดใช้

  1. เปิด Google Chrome บนคอมพิวเตอร์ (ไม่รองรับเบราว์เซอร์ Chromium อื่นและมือถือ)
  2. ติดตั้ง Claude จาก Chrome Web Store → กด Add to Chrome
  3. เข้าสู่ระบบด้วยบัญชี Claude แล้วปักหมุด (Pin) ไอคอนไว้ที่แถบเครื่องมือ และอนุญาตสิทธิ์ที่ขอ
  4. ใช้กับ Cowork: ใน Claude Desktop ไปที่ Settings → Customize → Connectors เปิด Claude in Chrome แล้วเปิดใช้ในแต่ละแชท (ค่าเริ่มต้นปิดอยู่)

ต้องใช้บัญชี Claude แบบเสียเงิน (Pro, Max, Team, Enterprise) สำหรับบัญชีองค์กร ผู้ดูแลระบบต้องเปิดสิทธิ์ให้ก่อน และอาจกำหนดเว็บที่อนุญาตไว้

ใช้ทำอะไรได้บ้าง

  • อ่านและสรุปหน้าเว็บ ที่เปิดอยู่ หรือเปิดหลายแท็บแล้วเปรียบเทียบให้
  • ค้นและดึงข้อมูล จากเว็บมาจัดเป็นตาราง แล้วให้ Cowork บันทึกเป็นไฟล์ Excel / Word
  • กรอกฟอร์มหรือทำขั้นตอนซ้ำ ๆ บนเว็บ โดยหยุดถามก่อนกดส่ง
  • Shortcut (Prompt ที่บันทึกไว้ใช้ซ้ำ) พิมพ์ / เพื่อเรียกใช้ และตั้งเวลาให้รันอัตโนมัติรายวัน / รายสัปดาห์ได้ (Chrome ต้องเปิดอยู่)
